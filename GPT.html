01

The Mental Model

Before code: understand what a linked list actually is.

FINAL / MIDTERM

A linked list is a collection of nodes. Every node stores some data and a pointer that tells us where the next node is. 

SINGLY

HEAD
  |
  v
[ 10 | next ] ----> [ 20 | next ] ----> [ 30 | next ] ----> NULL

Think of next as an arrow. If node 10's next contains the address of node 20, the arrow is: 

node 10's next
      |
      v
   [ node 20 ]

The Three Structures

→

Singly

Each node has next. Last node points to NULL.

↔

Doubly

Each node has prev and next. Can move both directions.

↻

Circular

Last node's next points back to Head. There is no NULL at the end.

Core Idea

The biggest conceptual difference is extremely simple: Singly → last points NULL, Circular → last points Head, Doubly → every connection has forward + backward links.

Node Structures

class Node {
public:
    int data;
    Node* next;
};
class Node {
public:
    int data;
    Node* prev;
    Node* next;
};
Critical Trap

Do not think Node* next stores the next node's data. It stores the address of the next node.

02

Singly Linked List

One direction: current node → next node.

CORE 
HEAD
 |
 v
[10] → [20] → [30] → [40] → NULL

Basic Node

class Node {
public:
    int data;
    Node* next;

    Node(int value) {
        data = value;
        next = nullptr;
    }
};

Important Rules

  • Head stores the address of the first node.
  • Each node's next stores the address of the next node.
  • The last node has next = nullptr.
  • To move forward: temp = temp->next.
Pro Tip

When you see temp->next, read it as: "the next pointer inside the node currently pointed to by temp."

2A

Singly LL — Functions

The standard operations you should know for an exam.

1. Insert at Beginning

Suppose:

HEAD → [20] → [30] → NULL

Want to insert 10:

HEAD → [10] → [20] → [30] → NULL

void insertAtBeginning(int value) {
    Node* newNode = new Node(value);

    newNode->next = head;
    head = newNode;
}

Only two important changes:

  1. New node points to old Head.
  2. Head moves to the new node.

2. Insert at End

HEAD → [10] → [20] → NULL

Find last node:
             temp
              |
              v
HEAD → [10] → [20] → NULL

Then:
[20].next = newNode
newNode.next = NULL

void insertAtEnd(int value) {
    Node* newNode = new Node(value);

    if (head == nullptr) {
        head = newNode;
        return;
    }

    Node* temp = head;

    while (temp->next != nullptr) {
        temp = temp->next;
    }

    temp->next = newNode;
}
Why this loop?

temp->next != nullptr means: keep moving while there is another node. When it becomes false, temp is the last node.

3. Traverse / Display

Node* temp = head;

while (temp != nullptr) {
    cout << temp->data << " ";
    temp = temp->next;
}

This visits: 10 → 20 → 30 → NULL.

4. Search

bool search(int key) {
    Node* temp = head;

    while (temp != nullptr) {
        if (temp->data == key)
            return true;

        temp = temp->next;
    }

    return false;
}

5. Insert After a Node

Suppose we have:

[10] → [20] → [30] → NULL

Insert 25 after 20:

[10] → [20] → [25] → [30] → NULL

Node* newNode = new Node(25);

newNode->next = temp->next;
temp->next = newNode;
Remember the Order

First save the old connection in the new node: new → old next. Then make current point to new: current → new.

6. Delete from Beginning

if (head == nullptr)
    return;

Node* temp = head;
head = head->next;
delete temp;

7. Delete from End

if (head == nullptr)
    return;

if (head->next == nullptr) {
    delete head;
    head = nullptr;
    return;
}

Node* temp = head;

while (temp->next->next != nullptr) {
    temp = temp->next;
}

delete temp->next;
temp->next = nullptr;
Important

To delete the last node, you normally need to stand on the second-last node. That is why we use: temp->next->next != nullptr.

8. Delete a Specific Node

Node* temp = head;

while (temp->next != nullptr) {

    if (temp->next->data == key) {
        Node* del = temp->next;
        temp->next = del->next;
        delete del;
        return;
    }

    temp = temp->next;
}

Notice that temp is kept at the node before the node we want to delete.

2B

Position Loops

One of the most important things to understand rather than memorize.

EXAM TRAP

Exact Position — 1-Based

for (int i = 1;
     i < position && temp != nullptr;
     i++) {

    temp = temp->next;
}

If position = 3: 

Initial:
i = 1
temp = node 1

i < 3 → move
i = 2
temp = node 2

i < 3 → move
i = 3
temp = node 3

3 < 3 → FALSE

STOP → temp is node 3
Meaning

i = 1; i < position makes temp stop at the exact position when using 1-based positions.

One Position Before — 1-Based

for (int i = 1;
     i < position - 1 && temp != nullptr;
     i++) {

    temp = temp->next;
}

This is useful when insertion is performed using: 

newNode->next = temp->next;
temp->next = newNode;

Here temp must be the node before the insertion position.

Exact Position — 0-Based

int index = 0;

while (temp != nullptr && index < pos) {
    temp = temp->next;
    index++;
}
Index:    0       1       2       3
          ↓       ↓       ↓       ↓
        [10] → [20] → [30] → [40]

pos = 2

index 0 → move to 20 → index 1
index 1 → move to 30 → index 2
index 2 < 2 ? NO

STOP → temp = [30]
Memorize This Pattern

index = 0 + index < pos → exact 0-based position.
i = 1 + i < position − 1 → one before 1-based insertion.

03

Doubly Linked List

Every node knows both its previous and next node.

CORE 
NULL ← [10] ⇄ [20] ⇄ [30] → NULL
         ↑             ↑
       prev/next     prev/next

Node

class Node {
public:
    int data;
    Node* prev;
    Node* next;

    Node(int value) {
        data = value;
        prev = nullptr;
        next = nullptr;
    }
};

The Two Extra Rules

  • First node: head->prev = nullptr.
  • Last node: tail->next = nullptr.
Why Doubly?

Singly can only travel: next → next → next. Doubly can travel: next or prev.

3A

Doubly LL — Functions

The main difference: more pointers must be updated.

1. Insert at Beginning

Before:

NULL ← [20] ⇄ [30] → NULL
        HEAD

After inserting 10:

NULL ← [10] ⇄ [20] ⇄ [30] → NULL
        HEAD

void insertAtBeginning(int value) {
    Node* newNode = new Node(value);

    newNode->next = head;

    if (head != nullptr)
        head->prev = newNode;

    head = newNode;
}

Four conceptual things to remember:

  1. New node's next = old head.
  2. Old head's prev = new node.
  3. New node's prev remains NULL.
  4. Head = new node.

2. Insert at End

If you have a tail pointer, this becomes very easy. 

void insertAtEnd(int value) {
    Node* newNode = new Node(value);

    if (head == nullptr) {
        head = tail = newNode;
        return;
    }

    tail->next = newNode;
    newNode->prev = tail;
    tail = newNode;
}

3. Traverse Forward

Node* temp = head;

while (temp != nullptr) {
    cout << temp->data << " ";
    temp = temp->next;
}

4. Traverse Backward

Node* temp = tail;

while (temp != nullptr) {
    cout << temp->data << " ";
    temp = temp->prev;
}

5. Insert in the Middle

Before:

[A] ⇄ [B] ⇄ [C]

Insert X between B and C:

[A] ⇄ [B] ⇄ [X] ⇄ [C]

Four links need to be correct: 

newNode->next = temp->next;
newNode->prev = temp;

temp->next->prev = newNode;
temp->next = newNode;
Doubly LL Trap

In a doubly linked list, inserting between two nodes usually requires four pointer updates, not two. Forgetting one of them can break backward traversal.

6. Delete from Beginning

if (head == nullptr)
    return;

Node* temp = head;

if (head == tail) {
    head = tail = nullptr;
}
else {
    head = head->next;
    head->prev = nullptr;
}

delete temp;

7. Delete from End

if (head == nullptr)
    return;

Node* temp = tail;

if (head == tail) {
    head = tail = nullptr;
}
else {
    tail = tail->prev;
    tail->next = nullptr;
}

delete temp;

8. Delete a Middle Node

Before:

[A] ⇄ [B] ⇄ [C]

Delete B:

[A] ⇄ [C]

Node* del = temp;

del->prev->next = del->next;
del->next->prev = del->prev;

delete del;
Easy Way to Think

When deleting B, make A skip B and make C skip backward over B: A → C and C → A.

9. Search

Node* temp = head;

while (temp != nullptr) {
    if (temp->data == key) {
        cout << "Found";
        return;
    }

    temp = temp->next;
}

cout << "Not found";
04

Circular Singly Linked List

Same next pointer as singly — but the last node points back to Head.

CORE 
              ┌─────────────────────────┐
              │                         │
              ▼                         │
HEAD → [10] → [20] → [30] → [40] ──────┘
The One Big Difference

Singly: last->next = nullptr. Circular: last->next = Head.

One-Node Circular List

HEAD
 |
 v
[10]
 ↑ |
 └─┘

Head->next == Head

CircularLL(int value) {
    Head = new Node(value);
    Head->next = Head;
}

The node points to itself because it is both the first and last node.

4A

Circular LL — Functions

The operations are similar to singly, but NULL-based loops must change.

1. Insert at End

void insertAtEnd(int value) {
    Node* newNode = new Node(value);

    Node* temp = Head;

    while (temp->next != Head) {
        temp = temp->next;
    }

    temp->next = newNode;
    newNode->next = Head;
}

The loop: temp->next != Head finds the last node.

2. Insert at Beginning

This is slightly more complicated than singly because the last node must point to the new Head. 

void insertAtFirst(int value) {
    Node* newNode = new Node(value);

    Node* temp = Head;

    while (temp->next != Head) {
        temp = temp->next;
    }

    newNode->next = Head;
    temp->next = newNode;
    Head = newNode;
}
Before:

HEAD → [10] → [20] → [30]
         ↑             |
         └─────────────┘

Insert 5:

HEAD → [5] → [10] → [20] → [30]
 ↑                           |
 └───────────────────────────┘

3. Traverse / Print

You cannot use temp != nullptr because a circular list does not reach NULL. 

Node* temp = Head;

do {
    cout << temp->data << " ";
    temp = temp->next;
} while (temp != Head);
Critical Circular Trap

This is dangerous: while(temp != nullptr). In a circular list, temp will never become NULL. The loop can continue forever.

4. Search

Node* current = Head;

do {
    if (current->key == key) {
        cout << "Found";
        return;
    }

    current = current->next;

} while (current != Head);

cout << "Not found";

5. Insert After a Node

Node* newNode = new Node(value);

newNode->next = current->next;
current->next = newNode;

Exactly the same pointer idea as singly. Circularity automatically remains intact when the links are changed correctly.

6. Delete from Beginning

if (Head == nullptr)
    return;

if (Head->next == Head) {
    delete Head;
    Head = nullptr;
    return;
}

Node* last = Head;

while (last->next != Head)
    last = last->next;

Node* temp = Head;

Head = Head->next;
last->next = Head;

delete temp;

Why find the last node? Because after Head changes, the last node must point to the new Head.

7. Delete from End

if (Head == nullptr)
    return;

if (Head->next == Head) {
    delete Head;
    Head = nullptr;
    return;
}

Node* temp = Head;

while (temp->next->next != Head) {
    temp = temp->next;
}

Node* last = temp->next;

temp->next = Head;

delete last;

8. Delete by Key

if (Head == nullptr)
    return;

if (Head->key == key) {
    deleteFromBeginning();
    return;
}

Node* current = Head;

while (current->next != Head) {

    if (current->next->key == key) {
        Node* temp = current->next;
        current->next = temp->next;
        delete temp;
        return;
    }

    current = current->next;
}

9. Circular "Insert at Middle" by Key

The teacher's version used key ordering, not a numeric position. The idea was: 

void insertAtMid(int key, int data) {

    Node* current = Head;

    do {

        if (current->key == key) {
            // duplicate key
            return;
        }

        if ((current->key < key) &&
            (current->next->key > key)) {

            Node* newNode =
                new Node(key, data);

            newNode->next = current->next;
            current->next = newNode;

            return;
        }

        current = current->next;

    } while (current != Head);

    cout << "Suitable position not found.";
}
Teacher Code Assumption

This middle-insertion condition assumes the keys are already arranged in ascending order. If the list is 6 → 7 → 8 → 9 → 0 → 1, the condition for inserting key 2 may not be satisfied.

05

Critical Pointer Loops

These loop conditions are among the most important exam patterns.

HIGH PRIORITY

Find Last — Singly

while (temp->next != nullptr)
    temp = temp->next;

Stop when temp is the last node.

Find Second-Last — Singly

while (temp->next->next != nullptr)
    temp = temp->next;

Stop when temp is the second-last node.

Find Last — Circular

while (temp->next != Head)
    temp = temp->next;

Stop when temp is the last node. Why? Because the last node's next points to Head.

Find Second-Last — Circular

while (temp->next->next != Head)
    temp = temp->next;

Stop when temp is the second-last node.

Must Know

temp->next != Head → temp becomes LAST.
temp->next->next != Head → temp becomes SECOND-LAST.

Why Do-While in Circular Lists?

do {
    // process current node
    current = current->next;
} while (current != Head);

Starting at Head means we want to process Head first. Then we keep moving until we return to Head. 

HEAD → A → B → C
 ↑           |
 └───────────┘

Start: A
process A
move B
process B
move C
process C
move A
A == HEAD → STOP

Teacher's Circular Approach

The exact patterns from the circular-list implementation discussed in class.

Node with Key + Data

class Node {
public:
    int key;
    int data;
    Node* next;

    Node() :
        key(0),
        data(0),
        next(NULL) {}

    Node(int k, int d) :
        key(k),
        data(d),
        next(NULL) {}
};
Key vs Data

In this implementation, key and data are separate. For example: insertatmid(2, 3) means key = 2, data = 3.

Constructor

CircularLL(int k, int d) {
    Head = new Node(k, d);
    Head->next = Head;
}

This creates: Head → Head.

Teacher's Insert at End

void insertatEnd(int k, int d) {

    Node* end = new Node(k, d);

    Node* temp = Head;

    while (temp->next != Head)
        temp = temp->next;

    temp->next = end;
    end->next = Head;
}

Teacher's Insert at First

void insertatFirst(int k, int d) {

    Node* newnode = new Node(k, d);
    Node* temp = Head;

    while (temp->next != Head)
        temp = temp->next;

    newnode->next = Head;
    temp->next = newnode;
    Head = newnode;
}

If the main program first creates keys 6, 7, 8, 9 and then inserts 0, 1 at the beginning, the list becomes 1 → 0 → 6 → 7 → 8 → 9. Therefore a middle insertion function that expects sorted keys may not find a suitable location for key 2.

09

Exam Traps & Mistakes

The small details that cause pointer questions to go wrong.

MEMORIZE
Trap #1 — Circular + NULL

Never use while(temp != NULL) to traverse a normal circular list. It does not end at NULL.

Trap #2 — Last vs Second-Last

temp->next != Head → temp is LAST.
temp->next->next != Head → temp is SECOND-LAST.

Trap #3 — Losing the Remaining List

When inserting after temp, do not write: temp->next = newNode first and forget the old next address. You must first do: newNode->next = temp->next.

Trap #4 — Doubly Requires Both Directions

Changing only next in a doubly linked list can make forward traversal work while backward traversal becomes incorrect.

Trap #5 — One Node

Deletion from beginning/end must handle the one-node case separately. In a circular list: Head->next == Head means there is exactly one node.

Trap #6 — Position Indexing

Always determine whether the question uses 0-based or 1-based positions. Your loop can otherwise stop at the wrong node.

Trap #7 — Delete Needs the Right Pointer

In a singly/circular list, deleting a middle node usually means finding the previous node, because you need to change its next.

Pro Tip — Draw First

If a pointer question looks confusing, draw three boxes: A → B → C. Then write exactly which arrow each line of code changes.

Last-minute revision table.

Common Mistakes → Fixes

Mistake Correct Idea
Using NULL to stop circular traversal Stop when temp == Head.
Thinking next stores data next stores an address/pointer.

Final Exam Strategy

Do not memorize three completely different programs. Learn one basic singly linked list first. Then remember: Doubly = add prev, Circular = replace NULL with Head. Most of the operations are just pointer-arrow changes.
